Conexión con la base de datos

Pega la URL de tu Google Apps Script publicado como aplicación web (la que termina en /exec). El sistema la guarda en este navegador y la usa siempre, de forma automática, cada vez que abras World DJ Pool aquí.

Un paso antes de continuar

Para descargar enlaces del grupo, primero debes seguir nuestra cuenta de Instagram. Es un paso único: no hace falta repetirlo cada vez.
